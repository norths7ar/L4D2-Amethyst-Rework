## v1.1.0 — 2026-09-08

- 默认加载AstRedux模式

- AstRedux 不再提供玩家控制特感与 Tank 的入口。

### 玩法与平衡

- 波次调整在下一波生效，修正玩法菜单与当前人数 Profile 基线的比较及覆盖处理。
- 按人数配置 Jockey 血量：单人 275、双人 300、三至四人 325；单、双人启用 Jockey Skeet，阈值分别为 180、200，三至四人保持关闭。
- 恢复单人模式下被 Smoker 舌头控制时的使用操作窗口。
- 将木狙、AWP 与连狙替换统一为 Scout，收敛狙击枪平衡配置。
- 修复医疗包治疗后剩余虚血的保留，以及 AutoWipe 对站立生还者血量的处理。

### 提示与便利功能

- 增加物品轮廓提示；当前默认提示近距离、视线可见的止痛药，不提供隔墙高亮。
- 更新连接公告实现，增加较早的连接提示，调整玩家可见文案并减少重复聊天信息。
- 下一图投票在聊天中显示票数情况和随机候选信息。
- 增加独立管理员工具组件，整理玩法菜单与各组件的提示文本。

### 地图与维护

- 更新地图轮换列表，增加了一批Stripper。
- 将玩家管理、准备/暂停、初始装备、医疗包规则和管理员工具拆分为职责独立的组件，整理插件加载顺序与配置接口。
- 增加内容部署后重启的运维流程，以及崩溃诊断和基础性能观测工具。
- 精简静态集成校验，更新配置与服务器维护说明。

### 升级注意

- 默认模式现在是 AstRedux，不再使用中途试验过的 Public Coop 回退方案。

## v1.0.0 — 2026-09-04

首个整套配置版本。以下根据 `v1.0.0` 标签及此前提交回溯整理。

### 模式与基础架构

- 基于 Competitive Rework 整合 AstMod 药役，并跟进 AstMod 2.8.1 的配置与运行组件。
- 建立 AstRedux 作为当前 Coop/PVE 主线，保留 AstMod 兼容模式；AstFlex 暂停开发。
- AstRedux 使用声明式 1–4 人 Profile 代替 DAS 切换整份难度配置，集中管理人数基线；Tank 血量、近战伤害、Witch、冲锋枪换弹和 AutoWipe 由独立组件执行。
- 按通用、Competitive、Coop 和 AstMod Legacy 整理插件加载职责，复用 Rework 的模式切换与卸载流程。

### 玩法与平衡

- 将 AstRedux 特感波次刷新迁移到 SourcePawn 插件，支持 `!si` 临时调整、波次 HUD 和人数档位下的特感组合；超出基础配额的名额采用随机补充。
- 单至四人的默认波次分别为 10 秒 / 3 特感、10 秒 / 4 特感、26 秒 / 5 特感、22 秒 / 6 特感。
- 按人数调整普感数量、特感限制、冲锋枪换弹速度及部分交互时长；自动发药和击杀回血、补弹奖励默认关闭。
- 整理武器替换规则，以冲锋枪、单喷和栓狙为主要武器；各类狙击枪共用全队一个名额，并同步修正消音冲锋枪换弹基线。
- 恢复标准生还者 MVP 统计，接入 Tank、Witch 伤害与表现统计等现有组件。

### 玩家流程与便利功能

- 增加合作暂停、逐人准备恢复、暂停面板和管理员强制恢复入口。
- 整理 `!ast` 玩法菜单与投票入口，提供地图、章节和战役投票，并按战役信息处理地图选择。
- 增加独立战役切换组件，整理公告、管理员重启及队伍管理相关功能。

### 地图与维护

- 合入第三方地图补丁，并将 Ast 系列共享 Stripper 资产统一到 `cfg/stripper/astredux/`。
- 补充 AstMod 源码快照及所需编译依赖，建立配置加载链和关键资产的静态校验。
- 提供服务器部署、重启、控制台和健康检查等运维工具，整理配置分层与服务器操作文档。
- 修复无地图状态下的波次处理、换图后 AI 定时器残留，以及 Profile 配置延后下发和地图卸载时的组件状态处理。
