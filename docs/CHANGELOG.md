## v1.5.0 — 2026-09-20

- 改善 Charger 行为逻辑，尝试解决近距离反向跑动、冲锋时突然转向远处或身后目标的问题。
- 修复了 Hunter 协同空爆此前未向击杀者播放空爆音效的错误。

### 问题修复

## v1.4.0 — 2026-09-19

### 玩法

- AutoWipe 自动解控 改为只在所有人被控的情况下触发，不再考虑未被控、仅倒地或挂边的情况。
- 击杀回血基础回复量提高 1 点.低血量回复改为低于 20 时额外回 3，20 ~ 39 额外回2。
- 秒妹回血改为 5 / 8(秒杀) / 15(引秒)，且全局开启不受杀特回血功能开关影响。

### AI Tank增强

- 连跳停止距离再次从 135 下调为 85，增加适当的主动减速逻辑。水平速度上限为 360 。
- 继续尝试修复 生还者短平台（桌椅、能踩的护栏）横跳时，Tank寻敌混乱的问题。
- 将允许扔石头的距离范围从 300-800 缩小为 500-800，鼓励Tank追击生还者。

### 杂项

- 修复了 `player_manager` 在换图时没有保留玩家与角色对应关系的问题
- 修复了 Skill Detect 插件的若干判定、统计与措辞问题。
- 修复 AstRedux 拒绝安装教学过滤 VPK 的玩家连接的问题，保留其他文件的一致性检查。

### 关于 “教学过滤VPK”

[创意工坊订阅地址](https://steamcommunity.com/sharedfiles/filedetails/?id=3804175935)

独立的客户端 VPK 文件，不在本仓库内。通过覆盖 `scripts/instructor_lessons.txt` 的方式实现屏蔽部分新手提示，同时保留第三方地图的自定义内容以维护玩法。
代价是，如果服务器设置了 `sv_consistency 1` 就需要特殊插件来单独放行此文件，否则客户端连接会被拒绝。

- AI Tank 增加前方顺路的机会性打铁，以及经支撑、碰撞体和弹道检查的低障碍跳上、顶面短暂追击判断。

- 扩大医疗包清理范围：Confogl 新增默认关闭的 `confogl_remove_directkits`，启用后在回合初始扫描清理直接生成且无人持有的医疗包；不拦截玩家持有或使用。
- 物资发光扩展到医疗包、电击器和标准子弹堆。

### 问题修复

- AutoWipe 先结束非 Tank 特感控制，再调用引擎完整复起接口处理倒地、挂边状态及隐藏副武器恢复，修正仅清除倒地标志导致的近战丢失问题；保留原扣血与倒地次数规则，加入 Charger 搬运识别并取消跨回合残留计时器。AstMod Legacy AutoWipe 未改。
- 生还位置保留限定为换章加载：主动退出释放席位；成功进图后掉线不再创建或保留等待，已恢复身份不会因队伍事件重新阻塞准备。

### 地图与服务器维护

- 地图扫描改为跳过失败包和冲突战役并输出原因，其余正常战役照常更新清单；失败包修复后重新扫描，不再因单包错误阻止整批应用。
- Git 拉取最多重试 3 次；连续失败仍应用已上传 VPK 并重启，明确提示仓库未更新，不部署旧 checkout 文件或推进部署记录。
- 维护和部署默认使用 root，移除安装脚本对 ecs-user 的硬编码依赖；内容应用自动补齐 VPK 读取权限并以游戏账户检查，游戏仍以 l4d2 运行。

## v1.0.0 — 2026-09-04

以下内容基于 `v1.0.0` 标签及此前 commits 回溯整理。

### 模式与基础架构

- 基于 Competitive Rework 整合 AstMod 药役，并跟进 AstMod 2.8.1 的配置与运行组件。
- 建立 AstRedux 模式，保留 AstMod 兼容；AstFlex 是 AstRedux 的低难度版本，目前暂停开发。
- AstRedux 使用声明式 1–4 人 Profile 代替 DAS 切换整份难度配置；Tank 血量、近战伤害、Witch、冲锋枪换弹和 AutoWipe 由独立组件执行。
- 按通用、Competitive、Coop 和 AstMod Legacy 整理插件加载职责，复用 Rework 的模式切换与卸载流程。

### 玩法与平衡

- 将特感波次刷新迁移到 SourcePawn 插件，支持 `!si` 临时调整、波次 HUD 和人数档位下的特感组合；超出基础配额的名额采用随机补充。
- 单至四人的默认波次分别为 10 秒 / 3 特感、10 秒 / 4 特感、26 秒 / 5 特感、22 秒 / 6 特感。
- 按人数调整小丧尸数量、特感限制、冲锋枪换弹速度及部分交互时长；自动发药和击杀回血、击杀回子弹默认关闭。
- 整理武器替换规则，以冲锋枪、单喷和鸟狙为主要武器；狙击枪全队限1把，并同步修正 SMG 换弹时间。
- 改用标准版生还者 MVP 统计，接入 Tank、Witch 伤害与表现统计等现有组件。
