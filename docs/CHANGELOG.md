# 更新日志

## 未发布

## v1.2.0 — 2026-09-09

相对 `v1.1.0` 的更新。

### 玩法与玩家流程

- AstRedux 单喷备弹上限调整为 144，冲锋枪为 900；战役商店默认关闭，暂停购买和积分奖励，保留源码与配置。
- Tank 远处连跳接近、190 units 内停跳，修正地面禁跳判断；投石采用低抛角与移动提前量，保留原有出手速度和血量伤害。
- 增加特感解卡重新定位，保留原实体、血量、技能与波次计数；按位移、行动状态、视线和空间筛选。
- 口水配控按牛锤击、Hunter、Smoker、Jockey 排序；调整 Charger 对已控目标的处理。
- 新增 `si_targeting`，取消六类特感及 Tank 引擎寻敌中的胆汁目标保留待遇，保留普通感染者吸引和其余选人规则；移除 Charger 临时近身强制换人规则。
- Coop 准备倒计时取消全员归位；保留越界返回与手动返回入口并增加落点空间检查。
- 安全屋地面医疗包转药接入正式开局事件，补齐自动准备流程触发。
- `!ast` 有限机关尸潮改接 `l4d2_horde_equaliser`，默认关闭，按地图人数档位限制机关累计生成量；`mob_interval_limit` 恢复上游版本，AstRedux 不再加载。

### 功能与显示

- 增加个人追加延迟、PVE 旁观 HUD、原生模型帽子和基础称号菜单。
- 增加战役积分商店，支持配置奖励、商品和个人逐商品递增价格；换章与团灭保留账本，换战役清空。Witch 奖励暂为 0，电击器默认关闭。
- 统一组件命名，精简难度状态提示；恢复每波特感 HUD。
- 聊天称号保留原版颜色、消息模板与收件人，修复发言者看不到自己消息。
- Tank 伤害比例以实体最终出生血量为分母，修复 1200 伤害显示 150% 的问题。

### 地图与维护

- MapInfo 以 ZoneMod 非尸潮字段为基线，保留人数尸潮分档并合入 Cirno 地图；死亡丧钟改版第五关采用尸潮 30/90/120/233、禁克 20–99、止痛药 4。
- 运维工具分为 Linux 服务端工具与 Windows 操作入口。
- 文档集中到 `docs/`，区分架构笔记、项目说明和源码来源；恢复更新日志并跟踪开发计划。
- 补入 12 份插件源码候选或参考实现，记录已知版本差异；按功能整理源码入口与依赖目录，运行二进制保持不变。

## v1.1.0 — 2026-09-08

相对 `v1.0.0` 的更新。

### 模式与回合流程

- 默认加载AstRedux模式
- 移植并优化合并了药抗的暂停/准备相关组件
- 修复自动队伍分配、换图后生还位置的保留和恢复功能，以及旁观状态对准备流程的影响。
- AstRedux 不再提供玩家控制特感与 Tank 的入口。
- 延后 Coop 脚本初始化，避免地图尚未准备好时访问脚本状态。

### 玩法与平衡

- 波次调整在下一波生效，修正玩法菜单与当前人数 Profile 基线的比较及覆盖处理。
- 按人数配置 Jockey 血量：单人 275、双人 300、三至四人 325；单、双人启用 Jockey Skeet，阈值分别为 180、200，三至四人保持关闭。
- 恢复单人模式下被 Smoker 舌头控制时的使用操作窗口。
- 将木狙、AWP 与连狙替换统一为 Scout，收敛狙击枪平衡配置。
- 修复医疗包治疗后剩余虚血的保留，以及 AutoWipe 对站立生还者血量的处理。
- 增加剧情过场生还者伤害保护。
- 尸潮生成限制增加独立开关，但当前 AstRedux 默认关闭。

### 提示与便利功能

- 增加物品轮廓提示；当前默认提示近距离、视线可见的止痛药，不提供隔墙高亮。
- 更新连接公告实现，增加较早的连接提示，调整玩家可见文案并减少重复聊天信息。
- 下一图投票在聊天中显示票数情况和随机候选信息。
- 增加独立管理员工具组件，整理玩法菜单与各组件的提示文本。

### 地图与维护

- 更新地图轮换列表，增加了一批Stripper。
- 将玩家管理、准备/暂停、初始装备、医疗包规则和管理员工具拆分为职责独立的组件，整理插件加载顺序与配置接口。
- 增加内容部署后重启的运维流程，以及崩溃诊断和基础性能观测工具。
- 精简静态集成校验，更新配置与服务器维护说明。

### 升级注意

- 默认模式现在是 AstRedux，不再使用中途试验过的 Public Coop 回退方案。
- Coop 组件与部分配置接口有调整，例如特感波次相关Cvar使用 `wave_size` / `wave_interval`；维护自定义配置的服主需对照新的加载链与配置说明合并，不能只替换单个 SMX。
