# AstRedux 设计决策

AstRedux 希望玩家在有挑战、但不过分苛刻的战斗中磨练个人技术和团队配合。相比其他主流药役，压低武器强度，是希望大家更多依靠配合过关；移除生还者 AI，是因为它们难以配合真人，且 AstRedux 已经按人数调整难度，不必凑满四人才能开。

比起背熟每张地图的固定打法，或利用 AI 的固定反应解决战斗，更希望玩家从实战中掌握一些通用原则，根据现场情况作出判断。熟悉地图当然有帮助，但希望练出来的是换一张地图、换一种局面也能用上的本事。

本文按进入游戏、准备、游玩和战役衔接的顺序，记录玩法选择与理由。具体参数以配置文件为准，版本变化见[更新日志](CHANGELOG.md)，后续想法见[开发计划](ROADMAP.md)。

## 进入游戏

### 开场动画

第三方地图的开场可能包含剧情、机关说明或玩法提示，不宜一律跳过；但陌生地图反复灭团后，重看同一段动画也会打断节奏。因此兼顾初次了解地图的需要和重试时的便利。设置方法见[地图规则配置](configuration/map-rules.md#开场动画优先级)。

### 客户端教学过滤

配套 VPK 可[独立订阅](https://steamcommunity.com/sharedfiles/filedetails/?id=3804175935)，用于减少新手提示，同时保留第三方地图自定义教学。客户端应开启游戏提示，必要时执行 `gameinstructor_reload_lessons`。未安装者继续使用原版教学；Zone 系列保留自己的校验和教学设置。

## 准备与正式开局

准备阶段允许整理装备、双击喷漆丢弃物品，以及下水游泳。正式开局会关闭丢弃和游泳功能。

模块职责、方案变迁和故障证据统一记录在[准备、暂停与开局归位](configuration/ready-pause.md)。

## 游玩过程

### 武器选择

Uzi、Mac-10、木喷、铁喷的数据均与 ZoneMod 2.9.1b 相同。新增了 MP5，参数设定介于 UZI 和 MAC-10 之间，与 ZoneMod BETA （2026-10-13版本）不同。
狙击保留 Scout ，单发伤害 125，对 Tank 为 150。考虑到人数不同时 Tank血量不同，近战对 Tank 伤害固定为300，不再固定为 Tank 血量 5%。

### 补给与续航

医疗资源层面，目前会把肾上腺素替换为止痛药，普通医疗包和电击器移除，救援终点除外。保留了高难图的击杀回血功能，但是没有开启商店，因为我想让地图也成为难度的一部分，而不是氪金（积分）就能逛街

目前沿途的止痛药会按路线长度控制密度，并用空间间距避免扎堆。字段和覆盖方法见[资源规则配置](configuration/resource-rules.md)。

### 物资发现轮廓

玩家可在有效范围内隔墙看到已被发现的物品的轮廓，超距熄灭、走近恢复；默认范围为 600 Source 单位。医疗箱里的物资在开箱后才能发现。目前只对医疗资源和弹药堆开启了此功能。

### 特感波次与人数适配

特感强度随人数调整，单人保留专属伤害规则。`!si` 和人数变化对波次的调整从下一波生效，当前波保持既定数量、间隔与阵容。

### Boomer

保留飞胖移动，加强转头喷吐和高差瞄准。命中补偿受实际喷吐、有效距离、角度与遮挡约束。喷吐CD降为 12 秒（而非原版的 20 秒）。

### Tank

以改善追击和地形通过为主，保留贴身博弈。加速连跳在距离 65 内停止、100 外恢复，中间保持原状态，减少追近时反复启停；转向和普通障碍跳跃配合追人。

受阻时先尝试局部脱困，持续停滞 8 秒后尝试传送到隐藏、可返回战场且距生还者至少 300 的位置。生还者能看到倒计时与结果提示，暂停期间计时停止。窄物体追击仍受地图导航质量影响。

### AutoWipe 自动解控

AutoWipe 为 2–4 人提供全员被控时的容错。倒地、挂边与被控混合的残局仍需正常救援，避免 Tank 战中最后一人被控就让全队获救。

默认代价为本次被控期间损失至少 40 总血量，已受伤害可以抵扣。补扣先实血后虚血，血量不足时消耗倒地次数；已倒地者沿用救起规则。正常解控后重新计数，Charger 搬运接砸地算同一次控制。

### 技巧击杀与奖励

空爆音效在击杀者一侧播放。启用普通特感击杀回血后，基础回血为 2；实血 20–39 额外加 2，低于 20 额外加 3，再叠加技巧奖励。

| 击杀行为 | 奖励档位 | 额外实血 |
| --- | --- | --- |
| 普通特感击杀 | 无 | 0 |
| Hunter 协同空爆 | 无（播报一星） | 0 |
| Hunter 普通单人空爆 | 一星 | +1 |
| Hunter 空爆：近战、马格南爆头、狙击爆头、榴弹直击 | 二星 | +2 |
| Hunter 空爆：单喷一喷、微冲≤3发 | 二星 | +2 |
| 残血击倒冲锋 | 二星 | +2 |
| 满血击倒冲锋（目前做不到） | 三星 | +3 |
| 打死正在控制自己的 Smoker，完成自救 | 二星 | +2 |
| Jockey 空爆 | 二星 | +2 |
| Boomer 0.5 秒内干净击杀 | 三星 | +3 |
| Boomer 0.5–1.4 秒干净击杀 | 二星 | +2 |

单喷一喷、微冲三发及以内要求独立完成击杀；近战、马格南／狙击爆头、榴弹直击按最终击杀技巧分类，允许队友此前补伤害。Boomer 的时间从出生算到死亡，“干净击杀”要求喷吐与爆炸均未使生还者中胆汁。

Witch 回血单独开关，普通击杀／秒妹／引秒分别恢复 5／8／15 实血，每次只结算对应一档。奖励针对实际击杀；Tank 单独播报战斗统计。

### 地图机关与救援

地图流程、机关和补给运营都是难度的一部分。地图专属的固定补给、弹药堆和流程调整按实际问题维护；第三方地图兼容是长期要求。

普通投掷物和可燃物默认禁用，灌油任务油桶照常保留。第三方机关需要特殊物资时，可用 `!ast` 的兼容投票放行榴弹、油桶与烟花、煤气罐与氧气瓶。

路程 Boss 和救援 Tank 轮次可通过 `!mset` 调整，见[地图规则配置](configuration/map-rules.md)。

## 战役衔接

### 地图切换

`!mapvote`、`!chaptervote`、`!nextmap` 提供地图与战役投票，终章结束后衔接下一战役。这些功能由服务器统一提供。

空服且连接、席位预留均结束后，默认等待 15 秒切到随机官图；已经处于官图则留在本图等待。地图清单处理见[地图内容处理](../ops/README.md#地图内容处理)，服务器设置见[服务器运维](server-operations.md#配置与地图维护)。

## 辅助与管理

### fakelag 模拟延迟

`!fakelag [毫秒]` 设置自身追加延迟，管理员可用 `!fakelag <玩家> <毫秒>` 指定玩家，`!printlag` 查询所有真人玩家。扩展使用[上游 custom_fakelag](https://github.com/ProdigySim/custom_fakelag)。

### 管理员工具

`!admin` 中，“管理玩家”提供传送、穿墙，“玩家辅助”提供回血、回弹、复活和生成，“服务器命令”提供取消投票。

准备阶段可用 `!guns` 或“生成 T1 武器”处理起点缺枪。每次在瞄准位置附近生成 T1 武器各一把；名单通过 `astredux.cfg` 的 `admin_guns_weapons` 调整。

管理员生成的特感独立于正常波次和人数禁刷规则，适合测试及临时干预。
