# AstRedux 设计决策

本文按进入游戏、准备、游玩和战役衔接的顺序，记录玩法选择与理由。具体参数以配置文件为准，版本变化见[更新日志](CHANGELOG.md)，后续想法见[开发计划](ROADMAP.md)。

## 进入游戏

### 入队与席位

支持 1–4 人动态难度。换章节为上一关的生还者预留席位，优先让原队伍继续游玩；首次自动入队后，玩家自行选择旁观或闲置。身份尚未确认的玩家先在旁观等待。

### 开场动画

官图默认跳过开场镜头，第三方地图可以单独设置；其他情况按本章队伍尝试次数决定。同章重开累计次数，换章节重新计数。跳过开场后，关卡后续剧情保留。设置方法见[地图规则配置](configuration/map-rules.md#开场动画优先级)。

### 客户端教学过滤

配套 VPK 可[独立订阅](https://steamcommunity.com/sharedfiles/filedetails/?id=3804175935)，用于减少新手提示，同时保留第三方地图自定义教学。客户端应开启游戏提示，必要时执行 `gameinstructor_reload_lessons`。未安装者继续使用原版教学；Zone 系列保留自己的校验和教学设置。

## 准备与正式开局

准备阶段允许整理装备、双击喷漆丢弃主副武器，以及在开启游泳功能时下水活动。正式开局统一发放装备、药品与血量，并关闭丢弃和游泳功能。

倒计时前将生还者安置到安全落点，再冻结位置，兼顾低矮起点和周围可坠落地形。`!return` 与出界返回使用相同的安全要求；找不到落点时限制相关玩家移动，待安全安置后继续开局。

开始倒计时后固定准备名单，原参与者取消准备或离队会中止倒计时。后来加入者须安全落地后才能继续计时。同图重开重新准备，局中暂停结束后继续当前回合。

## 游玩过程

### 武器选择

以 T1 武器为主，T2 大枪降级为小枪，狙击仅保留 Scout。Uzi 与 MAC-10 延续 ZoneMod 的精度／威力差异，MP5 作为第三种常规微冲参与刷新。单喷保持克制，避免武器过强；Scout 单发伤害 125，对 Tank 为 150。

手枪、马格南和近战沿用原版属性，电锯替换为随机近战。地面武器采用有限拾取，弹药堆仍可重复补弹。

### 补给与续航

药品是主要续航：普通医疗包和电击器移除，肾上腺素换药，救援终点的医疗包也换药。起终点原有药品保留，让队伍在第一波失误或堵门后有回头补给的机会。

谁吃药、何时回头取药是药役的资源决策，因此续航依靠地图补给和可选的击杀回血，而非商店。地图随机补给每轮重新选择，让重开也保留变化。

沿途药品按路线长度控制密度，并用空间间距避免扎堆。当前密度为每 1000 路线单位 `0.3` 个、最小间距 `500`，地图可设置例外；起终点补给与玩家随身物品豁免。筛选只减少地图已有资源，实际数量取决于原始刷点。

救援关侧重区域内持续作战，跳过路线密度筛选，保留数量上限和空间间距。C1M4、C6M3、C14M2 放开原生补给点，维持原有灌油需求。字段和覆盖方法见[资源规则配置](configuration/resource-rules.md)。

### 物资发现轮廓

玩家与物资之间无遮挡时，全队共享发现结果。发现后可在范围内隔墙看到轮廓，超距熄灭、走近恢复；默认范围为 600 Source 单位。医疗箱里的物资在开箱后才能发现，耗尽的物资停止高亮。

### 特感波次与人数适配

特感强度随人数调整，单人保留专属伤害规则，2–4 人的 Smoker 拖拽与窒息伤害沿用 ZoneMod。`!si` 和人数变化对波次的调整从下一波生效，当前波保持既定数量、间隔与阵容。

小波次轮换各类特感，避免少数类型反复占满名额；较大波次按基础阵容扩充。Tank 出生不受普通特感波次拦截。特感保留正常叫声和攻击音效，出生音乐沿用 Versus 规则。

### Boomer

保留飞胖移动，加强转头喷吐和高差瞄准。命中补偿受实际喷吐、有效距离、角度与遮挡约束。喷吐冷却为 12 秒，被推后仍需等待原有冷却结束。

### Tank

以改善追击和地形通过为主，保留贴身博弈。加速连跳在距离 65 内停止、100 外恢复，中间保持原状态，减少追近时反复启停；转向和普通障碍跳跃配合追人。

受阻时先尝试局部脱困，持续停滞 8 秒后尝试传送到隐藏、可返回战场且距生还者至少 300 的位置。生还者能看到倒计时与结果提示，暂停期间计时停止。窄物体追击仍受地图导航质量影响。

### Witch

单人禁刷，正式开局按队伍人数处理地图 Witch，使准备期间陆续加入的队友能影响本轮规则。static 表示关闭额外路程 Witch，地图固定 Witch 仍受人数规则管理。

Witch 显示白色轮廓，近身或惊扰后永久熄灭。战斗统计区分普通击杀、秒妹和引秒，奖励见下文。

### AutoWipe 自动解控

AutoWipe 为 2–4 人提供全员被控时的容错。倒地、挂边与被控混合的残局仍需正常救援，避免 Tank 战中最后一人被控就让全队获救。

默认代价为本次被控期间损失至少 40 总血量，实血和有效虚血一起计算，已受伤害抵扣这份代价。补扣先实血后虚血，血量不足时消耗倒地次数；已倒地者沿用救起规则。正常解控后重新计数，Charger 搬运接砸地算同一次控制。

### 技巧击杀与奖励

空爆音效在击杀者一侧播放。启用普通特感击杀回血后，基础回血为 2；实血 20–39 额外加 2，低于 20 额外加 3，再叠加技巧奖励。

| 击杀行为 | 奖励档位 | 额外实血 |
| --- | --- | --- |
| 普通特感击杀 | 无 | 0 |
| Hunter 协同空爆 | 无（播报一星） | 0 |
| Hunter 普通单人空爆 | 一星 | +1 |
| Hunter 空爆：近战、马格南爆头、狙击爆头、榴弹直击 | 二星 | +2 |
| Hunter 空爆：单喷一喷、微冲≤3发 | 二星 | +2 |
| 残血击倒冲锋 | 二星 | +2 |
| 满血击倒冲锋（目前做不到） | 三星 | +3 |
| 打死正在控制自己的 Smoker，完成自救 | 二星 | +2 |
| Jockey 空爆 | 二星 | +2 |
| Boomer 0.5 秒内干净击杀 | 三星 | +3 |
| Boomer 0.5–1.4 秒干净击杀 | 二星 | +2 |
| Boomer 1.4–2 秒干净击杀 | 一星 | +1 |

单喷一喷、微冲三发及以内要求独立完成击杀；近战、马格南／狙击爆头、榴弹直击按最终击杀技巧分类，允许队友此前补伤害。Boomer 的时间从出生算到死亡，“干净击杀”要求喷吐与爆炸均未使生还者中胆汁。

Witch 回血单独开关，普通击杀／秒妹／引秒分别恢复 5／8／15 实血，每次只结算对应一档。奖励针对实际击杀；Tank 单独播报战斗统计。

击杀回弹默认关闭，启用后补充完成击杀的主武器备弹，受备弹上限约束。

### 地图机关与救援

地图流程、机关和补给运营都是难度的一部分。地图专属的固定补给、弹药堆和流程调整按实际问题维护；第三方地图兼容是长期要求。

普通投掷物和可燃物默认禁用，灌油任务油桶照常保留。第三方机关需要特殊物资时，可用 `!ast` 的兼容投票放行榴弹、油桶与烟花、煤气罐与氧气瓶。投票放行地图已有资源，同战役内持续有效，换战役重置。

救援到来时保留场上已存活的 Tank，后续逃生 Tank 则继续拦截。路程 Boss 和救援 Tank 轮次可通过 `!mset` 调整，见[地图规则配置](configuration/map-rules.md)。

## 战役衔接

### 地图切换

`!mapvote`、`!chaptervote`、`!nextmap` 提供地图与战役投票，终章结束后衔接下一战役。这些功能由服务器统一提供。

空服且连接、席位预留均结束后，默认等待 15 秒切到随机官图，保持当前玩法模式；已经处于官图则留在本图等待。地图清单处理见[地图内容处理](../ops/README.md#地图内容处理)，服务器设置见[服务器运维](server-operations.md#配置与地图维护)。

## 辅助与管理

### fakelag 模拟延迟

`!fakelag [毫秒]` 设置自身追加延迟，管理员可用 `!fakelag <玩家> <毫秒>` 指定玩家，`!printlag` 查询所有真人玩家。扩展使用[上游 custom_fakelag](https://github.com/ProdigySim/custom_fakelag)。

### 管理员工具

`!admin` 中，“管理玩家”提供传送、穿墙，“玩家辅助”提供回血、回弹、复活和生成，“服务器命令”提供取消投票。

准备阶段可用 `!guns` 或“生成 T1 武器”处理起点缺枪，需 `n`（cheats）权限。每次在瞄准位置附近生成一套 T1 武器，各一把、拾取后消失；名单通过 `astredux.cfg` 的 `admin_guns_weapons` 调整。

管理员生成的特感独立于正常波次和人数禁刷规则，适合测试及临时干预。
