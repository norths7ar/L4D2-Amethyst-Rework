# AstRedux 设计决策

AstRedux 希望玩家在有挑战、但不过分苛刻的战斗中磨练个人技术和团队配合。相比其他主流药役，压低武器强度，是希望大家更多依靠配合过关；移除生还者 AI，是因为它们难以配合真人，且 AstRedux 已经按人数调整难度，不必凑满四人才能开。

比起背熟每张地图的固定打法，或利用 AI 的固定反应解决战斗，更希望玩家从实战中掌握一些通用原则，根据现场情况作出判断。熟悉地图当然有帮助，但希望练出来的是换一张地图、换一种局面也能用上的本事。

本文按进入游戏、准备、游玩和战役衔接的顺序，记录玩法选择与理由。具体参数以配置文件为准，版本变化见[更新日志](CHANGELOG.md)，后续想法见[开发计划](ROADMAP.md)。

## 进入游戏

### 开场动画

第三方地图的开场可能包含剧情、机关说明或玩法提示，不宜一律跳过；但陌生地图反复灭团后，重看同一段动画也会打断节奏。因此保留初次了解地图的机会，重复尝试时再跳过。设置方法见[地图规则配置](configuration/map-rules.md#开场动画优先级)。

### 客户端教学过滤

配套 VPK 可[独立订阅](https://steamcommunity.com/sharedfiles/filedetails/?id=3804175935)，用于减少新手提示，同时保留第三方地图自定义教学。客户端需开启游戏提示，地图教学才能正常显示；未安装者继续使用原版教学。

## 准备与正式开局

准备阶段允许整理装备、双击喷漆丢弃物品和下水游泳，开局前统一归位，正式开局时关闭丢弃和游泳。这样既能在等人时自由活动，也能结束准备期的特殊保护，正常进入战斗。

归位方案为何几经调整，以及准备、暂停和开局的衔接，见[准备、暂停与开局归位](configuration/ready-pause.md)。

## 游玩过程

### 离场与断线恢复（测试功能）

正式开局后不接纳新人，但允许异常掉线的原玩家回来继续。恢复延续本轮的装备余量、血量和倒地次数，倒地者仍倒地，死亡者继续旁观；保存的装备不在原地重复掉落。重连后自动尝试恢复，失败可用 `!join` 重试。

优先回到掉线位置，队伍走远或原位置不可用时回到队友附近。主动退出、切换旁观或被踢不保留恢复资格；过关或重开后清空本轮存档。

### 武器选择

基础武器平衡以 ZoneMod 为参照。微冲换弹在四人时对齐上游，少人时保留相对的加速补偿，随上游基准一起调整。

狙击保留 Scout。近战对 Tank 使用固定伤害，避免按最大血量百分比结算时，单次近战伤害也随人数档位变化。

### 补给与续航

医疗资源以止痛药为主，沿途按路线长度控制密度，并用空间间距避免扎堆。救援守点需要持续作战，因此另行保留补给，不与沿途消耗共用额度。三方图难以逐图录入补给区域，便通过自动识别补足覆盖；具体规则见[资源规则配置](configuration/resource-rules.md)。

保留高难图的击杀回血选项，但不开商店。地图的补给与路线本来就是难度的一部分，不希望靠积分购买绕过这些限制。

### 物品轮廓

物品轮廓包含几项独立提示：

- 医疗资源和弹药堆被发现后，在有效范围内可隔墙看到，帮助队伍记住尚未取用的物资；医疗柜开门后才显示其中的补给。
- Tank 存活时，用橙色轮廓提示铁，减少陌生地图初见杀。提示受距离与视线限制，保留观察周围环境的需要。
- Tank 卡住时，短暂显示红色轮廓，让玩家知道大概位置。
- 黑白队友显示白色人物轮廓，方便队伍判断救援与补给需求。

### 地图机关与救援

地图流程、机关和补给运营都是难度的一部分，第三方地图兼容是长期要求。

普通投掷物和可燃物默认禁用，灌油任务油桶照常保留。三方机关需要特殊物资时，可通过 `!ast` 的兼容投票放行。固定爆炸桶、路程 Boss 和救援 Tank 轮次则通过 `!mset` 调整，见[地图规则配置](configuration/map-rules.md)。

## 特感

### 特感波次与人数适配

特感强度随人数调整，单人另有伤害与自救规则。`!si` 和人数变化对波次的调整从下一波生效，当前波保持既定数量、间隔与阵容，避免战斗中途改变已经形成的压力。

各类特感的行为与调整理由见[特感 AI](configuration/special-infected-ai.md)。

### Boomer

飞胖保留快速接近和转头喷吐的威胁。少人时，高速接近迫使玩家仰头追枪，随后的遮视野与尸潮又容易破坏互救，因此降低少人档的起跳速度，给玩家更多提前处理的时间，同时保留接近后的喷吐能力。

各人数共用起跳算法，通过倍率调整接近强度；喷吐期间停止连跳。具体演变见[特感 AI](configuration/special-infected-ai.md)。

### Tank

Tank 增强以改善追击和地形通过为主，保留贴身博弈，不单纯增加动画倍速或连跳速度。优先补足反复攀爬、门后发呆等 AI 弱点。

此前增加踩障碍追击，是希望减少无谓绕路，但主动爬高也可能与原生寻路冲突。连跳、越障和攻击机会之间的协调仍在持续改进，具体取舍见[Tank AI](configuration/tank-ai.md)。

克局拦截机关尸潮的功能做了实验版加强，但是因来源无法区分，如果克局生还者打响警报车，那么地图机关尸潮同样会放行。管理员允许使用 `!stophorde` 在克局手动触发此功能。

### AutoWipe 自动解控

AutoWipe 为 2–4 人提供全员被控时的容错。代价按本次控制期间的总失血计算，已经承受的伤害可以抵扣；不足部分先扣实血、再扣虚血，血量不足时消耗倒地次数，已倒地者沿用救起规则。Charger 搬运接砸地算同一次控制。

开启普通特感击杀回血后，解控代价在基础档位上增加 20，避免回血抵消被控的风险。菜单仍显示基础档位：例如选择 40，开启回血后按 60 结算。Witch 回血单独开关，不参与这项联动。

### 技巧击杀与奖励

空爆音效在击杀者一侧播放。启用普通特感击杀回血后，基础回血为 2；实血 20–39 额外加 2，低于 20 额外加 3，再叠加技巧奖励。

| 击杀行为 | 奖励档位 | 额外实血 |
| --- | --- | --- |
| 普通特感击杀 | 无 | 0 |
| Hunter 协同空爆 | 无（播报一星） | 0 |
| Hunter 普通单人空爆 | 一星 | +1 |
| Hunter 空爆：近战、马格南爆头、狙击爆头、榴弹直击 | 二星 | +2 |
| Hunter 空爆：单喷一喷、微冲≤3发 | 二星 | +2 |
| 残血击倒冲锋 | 二星 | +2 |
| 满血击倒冲锋（目前做不到） | 三星 | +3 |
| 打死正在控制自己的 Smoker，完成自救 | 二星 | +2 |
| Jockey 空爆 | 二星 | +2 |
| Boomer 0.5 秒内干净击杀 | 三星 | +3 |
| Boomer 0.5–1.4 秒干净击杀 | 二星 | +2 |
| Boomer 1.4–2 秒干净击杀 | 一星 | +1 |
| Boomer 超过 2 秒的干净击杀（普通 Pop） | 无（播报一星） | 0 |

单喷一喷、微冲三发及以内要求独立完成击杀；近战、马格南／狙击爆头、榴弹直击按最终击杀技巧分类，允许队友此前补伤害。Boomer 的时间从出生算到死亡，“干净击杀”要求喷吐与爆炸均未使生还者中胆汁。

Witch 回血单独开关，普通击杀／秒妹／引秒分别恢复 5／8／15 实血，每次只结算对应一档。奖励针对实际击杀；Tank 单独播报战斗统计。

## 战役衔接

### 地图切换

`!mapvote`、`!chaptervote`、`!nextmap` 提供地图与战役投票，终章结束后衔接下一战役。

空服且连接、席位预留均结束后，回到随机官图，为下一批玩家保留稳定的进入起点；已经处于官图则留在本图等待。地图清单处理见[地图内容处理](../ops/README.md#地图内容处理)，服务器设置见[服务器运维](server-operations.md#配置与地图维护)。

## 辅助与管理

### fakelag 模拟延迟

`!fakelag [毫秒]` 为自己追加延迟，`!printlag` 查询真人玩家的设置，便于比较不同延迟下的游玩表现。

### 管理员工具

准备阶段可用 `!guns`、`!melee` 补充武器，处理部分地图缺物资的情况。`!mset` 用于修改当前地图规则。

管理员生成的特感独立于正常波次和人数禁刷规则，便于测试及临时干预。

`!stophorde` 可用于强制拦截克局期间的尸潮，适用于部分第三方地图。

`!readywarp [on|off]` 切换准备阶段归位传送，用于临时绕过地图卡头等问题；同关重开保留设置，换关恢复开启。
