# 地图规则配置

配置文件为 [`addons/sourcemod/configs/map_rules.cfg`](../../addons/sourcemod/configs/map_rules.cfg)，集中保存各地图的路程 Boss、救援轮次、开场动画与固定爆炸桶规则。AstRedux 通过 `map_rules_enabled 1` 使用它；Zone 系列继续使用原模式配置。

## 游戏内设置

管理员（`b`）输入 `!mset` 打开当前地图的设置。菜单显示当前状态，有待生效的修改时同时显示下轮状态。路程 Boss、救援轮次和开场设置在准备阶段修改本轮生效，正式开局后修改留到下轮；固定爆炸桶始终在下轮生效。设置按地图保存，灭团重开、换图和服务器重启后仍保留。

路程 Boss 也可以直接设置：

| 操作 | Tank | Witch |
| --- | --- | --- |
| 禁止路程刷新 | `!setstatictank` | `!setstaticwitch` |
| 查询本轮和保存值 | `!getstatictank` | `!getstaticwitch` |
| 恢复允许路程刷新 | `!unsetstatictank` | `!unsetstaticwitch` |

static 只禁止路程 Boss，不影响固定 Boss；恢复允许后仍遵守地图刷新区间。

救援关默认禁止路程 Tank，地图原有的救援／剧情 Tank 照常出现。本图的 `static_tank` 配置优先于默认值，也可通过 `!mset` 调整。该默认值由 `boss_spawn_rules` 管理，Witch 规则保持原样。

## 路程异常恢复

进度查询和路程 Boss 刷新依赖地图的路程数据。部分三方图首次计算正常，重开时却可能算不出完整路程，导致 `!cur` 不可用，路程 Tank 也无法按计划出现。

AstRedux 的 `l4d_flow_fallback` 会在这种情况下恢复同地图此前成功计算的完整结果；重算成功时使用新结果。它不改变地图阻挡规则和进度显示缓冲，也不属于 `!mset` 的地图开关。地图从未成功计算过完整路程时，没有可恢复的数据。

该修复当前支持 Linux 32 位服务端。

## 配置字段

文件按地图完整名称组织，`defaults` 为默认规则，`maps` 为各图规则。新图无需预先列入文件，游戏内修改时会新增当前地图条目。

| 字段 | 含义 |
| --- | --- |
| `static_tank` / `static_witch` | `1` 禁止对应路程 Boss；`0` 允许路程刷新 |
| `finale_mode` | `rounds` 为已知普通救援；`auto` 在确认普通救援阶段后开放编辑；`legacy` 使用预设救援规则，不提供菜单编辑 |
| `tank_round_1` / `tank_round_2` / `tank_round_later` | 对应救援第1轮、第2轮、第3轮及以后；`1` 允许，`0` 禁止。轮次不是同轮内每只 Tank 的编号 |
| `skip_intro` | `1` 本图始终跳过开场；`0` 按次数设置 |
| `fuel_barrels` | `1` 保留地图固定爆炸桶，`0` 禁止；AstRedux 默认 `0`，修改后下轮生效 |

手工编辑配置后，下一次回合开始读取；菜单和直接命令按各项目的生效时机应用。游戏内保存直接更新这份配置，每次只修改当前地图的对应字段，保留其他规则。

固定爆炸桶由 `map_entity_rules` 管理。遇到需要炸桶开路的机关，可在 `!mset` 允许后重开，恢复地图原桶；`!ast` 管理的则是可携带道具。把全局 Stripper 删除改为游戏内开关，是为了让初见三方图卡关时能直接处理。

## 救援轮次与逃生 Tank

轮次编辑用于已确认支持的普通救援；逃亡型救援使用预设规则。

AstRedux 在救援到来时保留已经存活的 AI Tank（`confogl_remove_existing_escape_tank 0`），包括灌油或其他地图流程已生成的 Tank；后续逃生 Tank 仍被禁止（`confogl_remove_escape_tank 1`）。这两项与救援轮次设置分开。

## 开场动画优先级

准备阶段按以下优先级处理：

1. `l4d_skip_intro_official 1`：默认开启，按内置官图完整名称匹配，始终跳过。
2. 本图 `skip_intro 1`：始终跳过，可用于接入第三方地图。
3. `l4d_skip_intro_play_count`：按本章队伍尝试次数决定是否跳过。

前两项均覆盖次数，包括 `-1`；开场跳过功能的总开关、模式限制和准备阶段策略开关仍然有效。官图无需写入配置名单。

AstRedux 设置 `l4d_skip_intro_ready 1`，在所有章节的准备阶段处理开场动画；正式开局后不再处理后续剧情。未启用此设置的模式仅处理首关开场。

### 开场动画播放次数

未命中前两项优先规则时，`l4d_skip_intro_play_count` 决定播放次数：

| 值 | 效果 |
| --- | --- |
| `2`（AstRedux 设置） | 本章前两次队伍尝试正常播放，第三次起跳过 |
| `0` | 始终跳过 |
| `-1` | 始终播放 |

次数按队伍计算：同章重开累计，重新进入准备阶段和玩家重连不增加，后来加入的玩家沿用队伍次数。换章节清零；服务器重启或插件重新加载后重新计数。

Dead City II 首关 `dc2m1_riverside` 的开场会连续切换镜头，通用跳过仍可能留下闪屏和黑屏。该图使用专用 Stripper 始终跳过这段开场，保留出生定位、角色释放和列车初始化，不受播放次数设置影响。
