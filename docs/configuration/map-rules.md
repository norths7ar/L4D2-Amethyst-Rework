# 地图规则配置

[`map_rules.cfg`](../../addons/sourcemod/configs/map_rules.cfg) 保存各地图的路程 Boss、救援轮次、开场动画与固定爆炸桶规则。AstRedux 使用这份配置；Zone 系列继续使用原模式配置。物资替换、数量和分布，包括单图物资特例，见[资源规则](resource-rules.md)。

## 游戏内设置

管理员（`b`）输入 `!mset` 打开当前地图的设置。菜单显示当前状态，有待生效的修改时同时显示下轮状态。路程 Boss、救援轮次和开场设置在准备阶段修改本轮生效，正式开局后修改留到下轮；固定爆炸桶始终在下轮生效。设置按地图保存，灭团重开、换图和服务器重启后仍保留。

新图无需预先列入配置，游戏内修改时会新增当前地图条目，每次只更新对应字段。手工编辑配置后，下一次回合开始读取；字段含义见配置文件注释。

## Boss 与救援轮次

static 只禁止路程 Boss，不影响地图剧情或救援流程生成的 Boss；恢复允许路程刷新后，仍遵守地图刷新区间。救援关默认禁止路程 Tank，本图显式设置优先，Witch 规则不随之改变。

轮次编辑用于已确认支持的普通救援，指第几轮救援阶段，不是同阶段内每只 Tank 的编号。逃亡型救援使用预设规则。救援到来时保留已经存活的 AI Tank、禁止后续逃生 Tank，是另外两项框架策略，不随轮次编辑改变。

## 固定爆炸桶

固定爆炸桶由 `map_entity_rules` 管理，与 `!ast` 管理的可携带道具不同。由全局 Stripper 删除改成地图开关，是为了在初见三方图遇到炸桶开路机关时，能通过 `!mset` 允许并重开恢复地图原桶，不必临时修改后台配置。需要修复地图实体连接或特定机关时，仍使用对应地图的 Stripper。

## 路程异常恢复

进度查询和路程 Boss 刷新依赖完整的地图路程数据。部分三方图首次计算正常，重开时却可能失败，导致 `!cur` 不可用、路程 Tank 无法按计划出现。

`l4d_flow_fallback` 会恢复同地图此前成功计算的完整结果，重算成功时使用新结果；从未成功计算过时无法恢复。该修复支持 Linux 32 位服务端，不改变地图阻挡规则和进度显示缓冲，也不是 `!mset` 的地图开关。

## 开场动画优先级

AstRedux 在各章节的准备阶段处理开场，正式开局后不再处理后续剧情。准备阶段按以下顺序决定是否跳过：

1. 官图强制跳过，按内置完整地图名匹配，无需另写名单。
2. 本图 `skip_intro` 强制跳过，可用于第三方地图。
3. 未命中前两项时，按 `l4d_skip_intro_play_count` 决定播放次数。

前两项覆盖次数设置，包括“始终播放”；开场功能总开关、模式限制和准备阶段策略开关仍然有效。

播放次数按本章队伍尝试计算，而不是按玩家计算。同章重开累计，重新进入准备阶段或玩家重连不增加，后来加入的玩家沿用队伍次数；换章节清零，计数不跨服务器重启或插件重载保存。例如次数设为 2 时，前两次正常播放，第三次起跳过；0 为始终跳过，-1 为始终播放。当前设置见[模式配置](../../cfg/cfgogl/astredux/astredux.cfg)。
